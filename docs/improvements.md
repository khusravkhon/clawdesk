# Минусы и улучшения

Разбор проекта на 13.11.2026 (первый разбор — 12.11.2026, цифры перепроверены по коду): что сделано хорошо,
что мешало и что с этим сделано. Идеи новых возможностей лежат отдельно, в [ideas.md](ideas.md).

## Итог

Основа крепкая: безопасная граница браузер → BFF → Gateway, строгие типы, тесты сервера, проверка каждой версии
OpenClaw на живом Gateway, обновление с откатом. 13.11.2026 закрыты все пункты разбора ниже, кроме сквозных
проверок Playwright (п. 2). Не проверено на живой системе: новый сценарий контрактного теста (нужен Docker, его
впервые прогонит CI) и поток «что изменилось» с настоящим Gateway.

## Что сделано хорошо

- **Граница безопасности.** Браузер говорит только с BFF, секреты и токен устройства остаются на сервере.
  Сессия в httpOnly-cookie, проверка Origin на изменяющих запросах, пауза после неудачных входов
  (`apps/bff/src/auth/auth-service.ts`, `apps/bff/src/routes/auth.ts`).
- **Обновления.** OpenClaw закреплён в одном файле (`deploy/openclaw.version`, сейчас 2026.8.35), каждую новую
  версию проверяет контрактный тест на живом Gateway, обновление делает копию и откатывается при сбое.
- **Тесты.** Сервер — 85 файлов, 573 теста; интерфейс — 6 файлов, 21 тест; отдельные тесты скриптов установки,
  копий и восстановления в `deploy/`. CI гоняет линтер, сборку, типы, тесты, shellcheck, контрактный тест и
  `cargo test` десктопа.
- **Строгие типы.** `strict` во всём репозитории, ни одного `@ts-ignore`. `packages/shared` даёт одни zod-схемы
  серверу и интерфейсу.
- **Переводы.** ru / en / tg совпадают по ключам один в один (2516 ключей); теперь это проверяет тест.
- **Честные состояния.** Экраны различают «нет данных», «не удалось проверить» и «устарело» вместо пустоты.
- **Десктоп.** Приложение на Tauri ставит панель по SSH, держит туннель и умеет восстановление
  (`apps/desktop/src-tauri/src`), так что новичку не нужен терминал.

## Минусы и что сделано 13.11.2026

### 1. Ошибки на стыке с OpenClaw находились руками — сценарий добавлен

Из последних 60 коммитов 31 — исправления, почти все найдены на живом сервере: двойные напоминания, копия со
ссылками, окно контекста бесплатных моделей.

**Сделано:** в контрактный тест (`apps/bff/src/contract/smoke.ts`) добавлен сценарий запуска по расписанию:
плагин `clawdesk-schedule-guard` загружен, `cron.run` запускает задачу, `cron.runs` показывает её завершение,
приходит событие `cron`, а попытка агента отправить сообщение самому блокируется. Копия со ссылками и окно контекста
уже покрыты тестами (`deploy/clawdesk-backup-links.test.mjs`, `apps/bff/test/free-models-context.test.ts`).
**Правило дальше:** каждую ошибку, найденную на сервере, превращать в такой сценарий.

### 2. У интерфейса не было ни тестов, ни линтера — сделано, кроме Playwright

**Сделано:** Biome 2.6.4 (`biome.json`, `pnpm lint`, шаг в CI) — только линтер, форматирование не навязывается.
Найденные им мелочи исправлены. Vitest в `apps/web/test`: расписания, форматирование, карта «Конвейера»,
вложения чата, повтор опроса, совпадение переводов.
**Осталось:** 3–5 сквозных проверок Playwright (вход, чат, агент, напоминание). Нужна загрузка браузера и
подставной сервер; отдельная задача.

### 3. Тяжёлая первая загрузка — сделано

Языки грузятся по требованию (`apps/web/src/i18n.ts`). Главный файл: 865 КБ → 311 КБ (83 КБ сжатым), плюс один
язык 133–215 КБ. Графики «Обзора» (521 КБ) по-прежнему грузятся только на нём.

### 4. Крупные файлы — начато

**Сделано:** из `ChatView.vue` вынесены выбор бесед (`components/ChatConversationBar.vue`) и проверка вложений
(`chat-attachments.ts`, с тестами): 1232 → 1105 строк.
**Дальше — по мере касания:** видео в чате, `ConveyorView.vue` (854), `SourcesView.vue` (759), `schema.ts` (800).

### 5. Обновление данных опросом — сделано

Новый поток «что изменилось» (`GET /api/changes/events`, `apps/bff/src/changes/`, `apps/web/src/changes.ts`):
сервер называет области (агенты, расписания, напоминания, материалы, запросы, задачи), экраны перезагружают
нужное сразу. Источники: успешные изменения через API панели и события Gateway `agent` и `cron`.
«Обзор», «Конвейер» и «Расписания» опрашивают раз в 2 минуты вместо 15–30 секунд, «Сегодня» — раз в минуту
(доставку напоминаний поток не видит), запросы и задачи компании — раз в 30 секунд вместо 10 (агенты меняют
их через плагин). Короткие таймеры остались там, где они нужны: часы чата, ожидание пары с Telegram, рестарт.

### 6. Интерфейс собран неровно — сделано

Три голых поля заменены на Naive UI: агент в «Материалах», «Отложить» и дата в «Сегодня». Поле названия беседы
в чате тоже. Цвета `#18a058` и индиго-рамка переведены на токены. Остались только цвета брендов (Google, Figma,
GitHub, Notion) и рисунок офиса, так задумано. Тема по умолчанию тёмная — решение владельца.

**Пустые состояния с одним действием:** «Материалы» → «Открыть чат», «Сегодня» → «Новое напоминание»,
«Проекты», «Команды», «Документы», агенты на «Обзоре» и «Состоянии» → кнопка создания.

### 7. Документация отставала — сделано

README: статус проверки на сервере и `pnpm lint`. `architecture.md`: версия OpenClaw берётся из
`deploy/openclaw.version`, UI-кит — Naive UI.

### 8. Защитные заголовки зависели от Caddy — сделано

BFF сам ставит `nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy` и CSP
(`apps/bff/src/security-headers.ts`, скрипты только свои). Caddy оставил себе HSTS. Предпросмотр сборщика проектов
теперь открывается по адресу со своей политикой, а не через `srcdoc`, иначе строгая CSP панели выключала бы его
скрипты. Сборка проверена в браузере под этой CSP: нарушений нет.

### 9. Миграции без отката — проверка добавлена

`apps/bff/test/migrations-rollback.test.ts` проходит все 38 миграций и требует, чтобы каждая была безопасна
для прежней версии: не удаляла таблицы и столбцы и не добавляла обязательных столбцов без значения по умолчанию.
Все нынешние миграции правилу соответствуют. Так прежний образ панели запускается на базе, которую уже обновил новый.
