# Минусы и улучшения

Разбор проекта на 12.11.2026: что сделано хорошо, что мешает и что улучшить в первую очередь.
Идеи новых возможностей лежат отдельно, в [ideas.md](ideas.md).

## Что сделано хорошо

- **Граница безопасности.** Браузер говорит только с BFF, секреты и токен устройства остаются на сервере.
  Сессия в httpOnly-cookie, проверка Origin на изменяющих запросах, пауза после неудачных входов
  (`apps/bff/src/auth/auth-service.ts`, `apps/bff/src/routes/auth.ts`).
- **Обновления.** OpenClaw закреплён в одном файле, каждую новую версию проверяет контрактный тест на живом
  Gateway, обновление делает копию и откатывается при сбое.
- **Тесты сервера.** 82 файла тестов в `apps/bff/test`, CI гоняет сборку, типы, тесты, shellcheck и контрактный тест.
- **Общие типы.** `packages/shared` даёт одни zod-схемы серверу и интерфейсу.
- **Переводы.** ru / en / tg совпадают по ключам один в один (проверено скриптом, расхождений 0).
- **Честные состояния.** Экраны различают «нет данных», «не удалось проверить» и «устарело» вместо пустоты.

## Минусы, по убыванию вреда

### 1. Интерфейс собран неровно

- Часть экранов написана на голых `<select>`, `<input>` и ссылках без оформления: «Сегодня», «Материалы»,
  «Настройки» (20 таких элементов в `apps/web/src/views`). Рядом с экранами на Naive UI они выглядят как черновик.
- 25 цветов вписаны прямо в компоненты мимо токенов `styles.css`, поэтому смена темы красит не всё.
- Тема не смотрит на настройку системы (`prefers-color-scheme` не используется), по умолчанию всегда тёмная.
- Обводка фокуса с клавиатуры задана только в 5 местах.

**Что сделать:** один набор токенов и общих классов, экраны из п. 1 перевести на него. Сделано 12.11.2026 для
личного режима: светлая тема, общие классы в `styles.css`, «Сегодня», «Материалы», «Настройки», чат, агенты.
Осталось пройти экраны режима компании и заменить оставшиеся цвета мимо токенов.

### 2. У интерфейса нет ни тестов, ни линтера

- В `apps/web` нет ни одного теста; CI проверяет только типы (`vue-tsc`).
- В репозитории нет ESLint, Prettier или Biome. Стиль держится на внимательности.

**Что сделать:** Vitest для чистой логики (`cron.ts`, `format.ts`, сборка графа «Конвейера») и 3–5 сквозных
проверок Playwright на главные пути: вход, чат, создание агента, напоминание. Biome одним конфигом на весь репозиторий.

### 3. Тяжёлая первая загрузка

- Главный файл интерфейса — 843 КБ, ещё 521 КБ графиков подгружается на «Обзоре» (`apps/web/dist/assets`).
- Все три языка (620 КБ JSON) вшиты в главный файл, хотя нужен один (`apps/web/src/i18n.ts`).

**Что сделать:** грузить язык по требованию (`import()` выбранного языка, остальные — при переключении).
Это уберёт около 400 КБ из первой загрузки без изменения экранов.

### 4. Крупные файлы, которые трудно менять

- `apps/web/src/views/ChatView.vue` — 1187 строк: отправка, вложения, поток, беседы и видео в одном файле.
- `apps/web/src/api/client.ts` — 546 строк и 180 импортов типов в одном объекте.
- `apps/bff/src/db/schema.ts` — 800 строк; `work-requests-service.ts` — 668; `telegram-service.ts` — 615.

**Что сделать:** делить по мере касания, не отдельным большим рефакторингом. Первым — ChatView:
вынести вложения и список бесед в компоненты.

### 5. Обновление данных опросом

- 11 таймеров `setInterval` в интерфейсе («Обзор», «Сегодня» и другие опрашивают сервер раз в 30 секунд),
  при том что поток событий (SSE) уже есть для чата, одобрений и активности.

**Что сделать:** один общий поток «что изменилось» и точечная перезагрузка разделов. Меньше запросов и живые экраны.

### 6. Документация отстаёт от кода

- `docs/architecture.md` описывает `packages/ui`, которого нет, и OpenClaw 2026.8.1 (сейчас 2026.8.35).
- В README статус «на настоящем сервере установка ещё не прогонялась», а в `company-mode.md` сервер проверен 07.11.2026.

**Что сделать:** поправить две строки статуса и структуру в `architecture.md`.

### 7. Защитные заголовки зависят от Caddy

- `nosniff`, `X-Frame-Options`, HSTS задаёт только Caddy (`deploy/Caddyfile`). При входе через SSH-туннель или
  десктоп панель отвечает без них. Политики CSP для самой панели нет нигде.

**Что сделать:** задавать заголовки в BFF (`apps/bff/src/app.ts`, хук `onSend`), добавить CSP `default-src 'self'`.

### 8. Миграции без отката

- 39 миграций применяются при старте, шагов назад нет; вернуться можно только из копии `before-update`.
  Это описано в `company-mode.md`, но остаётся риском при неудачном обновлении.

**Что сделать:** оставить как есть, но проверять в CI, что копия `before-update` поднимается на предыдущей версии.
