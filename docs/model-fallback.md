# Запасные модели и дешёвые API — план

Статус (2026-10-14): **главный агент — сделано**, остальное — план.

Сделано:
- Экран «Ассистент» → карточка «ИИ-модели» ([ModelChain.vue](../apps/web/src/components/ModelChain.vue)):
  основная + до 3 запасных, порядок стрелками, «Добавить» модель уже подключённого ИИ, «Подключить новый ИИ»
  (ключ или подписка) — новая модель встаёт **последней запасной**, основная не меняется.
- BFF: `GET/PUT /api/ai/models`, `asBackup` в `POST /api/ai/activate` и `POST /api/ai/signin`
  ([model-chain.ts](../apps/bff/src/ai-setup/model-chain.ts)). FreeLLMAPI главному агенту не ставится (400).
- Как «подключить как запасную», если OpenClaw умеет только «подключить как основную»: BFF запоминает цепочку
  до подключения, OpenClaw проверяет ключ и делает новую модель основной, затем BFF возвращает прежнюю цепочку и
  дописывает новую модель в конец. Неверный ключ — OpenClaw ничего не сохраняет, цепочка не трогается.
- **Проверено на Gateway:** `agents.update { model }` записывает модель **строкой и стирает `fallbacks`** —
  поэтому цепочка всегда пишется через `patchConfig` и восстанавливается из снимка.

Осталось: пресеты, младшие агенты и команды, `auth.order.openai` (подписка + ключ OpenAI одного провайдера),
галочка для расписаний, расход по фактической модели, уведомления о переключении в Telegram-группах.
Живой проверки с настоящим платным ключом ещё не было.

## Зачем

- Подписка ChatGPT Plus (вход через Codex) имеет два лимита: окно **5 часов** (вернули 25–26.08.2026) и
  **недельный**. Ориентир OpenAI — 15–150 сообщений за 5 ч на основной модели, 5–45 на тяжёлой.
- Агент тратит лимит быстрее чата: одна просьба владельца = 3–10 шагов (чтение файлов, инструменты, источники),
  в каждом шаге — память и описание инструментов. Расписания и Telegram едят тот же лимит.
- Когда лимит кончился, главный агент молчит до сброса окна. Для владельца это выглядит как «сломалось».
- Бесплатный ключ Google часто отвечает `503`/`429` — та же проблема.

Цель: агент **не замолкает**. Кончился лимит / деньги / провайдер перегружен → ход продолжает запасная модель,
владелец видит уведомление, следующий ход снова пробует основную.

## Что умеет OpenClaw 2026.8.1 (уже есть, писать не надо)

Источник: `docs/concepts/model-failover.md` в образе Gateway
(`MSYS_NO_PATHCONV=1 docker exec clawdesk-gateway-1 cat /app/docs/concepts/model-failover.md`).

Два уровня:

1. **Ротация профилей внутри провайдера** — `auth.order.<provider>`. Пример: подписка Codex + API-ключ OpenAI:
   ```json5
   { auth: { order: { openai: ["openai:user@example.com", "openai:api-key-backup"] } } }
   ```
   Codex сообщил «лимит» → OpenClaw запоминает время сброса, берёт следующий профиль, после сброса возвращается.
2. **Запасные модели** — `agents.entries.<id>.model { primary, fallbacks }`, могут быть **другого провайдера**.
   - У агента без `fallbacks` модель **строгая** — ошибка без переключения. Список надо задать явно.
   - Переход на следующую модель: auth, rate limit (включая `weekly limit reached`, `usage limit`), перегрузка,
     таймаут, billing («нет денег»).
   - **Не** переходит: переполнение контекста, явная отмена, отказ по безопасности.
   - Переключение **только на текущий ход**; следующий ход начинается с основной.
   - Остывание профиля: 30 с → 1 мин → 5 мин. «Нет денег» — профиль отключается надолго.
   - Если все перегружены — до 10 повторов хода (только пока агент ещё ничего не сделал), через 30 с сообщение
     «сервис перегружен, повторяю».
   - Уведомления: `↪️ Model Fallback: <запасная> (selected <основная>; <причина>)` и `↪️ Model Fallback cleared`.
     **В группах и каналах (Telegram-группы команд) уведомления не показываются** — только в личке.
   - Расписания (`cron`): своя модель в задаче использует общие `fallbacks`, если в задаче нет своих
     `payload.fallbacks`; `payload.fallbacks: []` — строго.
   - Модель, выбранная руками (`/model`, `sessions.patch`) — строгая, без переключения.
   - `OPENCLAW_FALLBACK_SKIP_TTL_MS=60000` — не стучаться повторно в запасную с ошибкой ключа (опционально).

Что уже делает панель: только для Gemini Flash — `#setGeminiFallbacks` в
[ai-setup-service.ts](../apps/bff/src/ai-setup/ai-setup-service.ts) пишет другие Flash-модели того же ключа
(`patchConfig` + `replacePaths: ["agents.entries.main.model.fallbacks"]`).

## Какие схемы предлагать (пресеты)

Владелец не должен думать о `fallbacks`. Панель предлагает готовые схемы, их можно поменять.

| Пресет | Основная | Запасная 1 | Запасная 2 |
|---|---|---|---|
| **Дёшево** (по умолчанию для новых) | DeepSeek V4 Flash | GLM-5.3-Flash | Gemini Flash (бесплатный ключ, только личный режим) |
| **Подписка + страховка** | ChatGPT Plus (Codex) | API-ключ OpenAI (тот же провайдер, `auth.order`) | DeepSeek V4 Flash |
| **Только бесплатно** (тест) | Gemini Flash (бесплатный) | `gemini-flash-latest` / `-lite-latest` | — |
| **Своя** | любая | любая | любая |

### Правила по агентам

- **Главный агент**: основная + до 2 запасных. Бесплатные модели (FreeLLMAPI) **никогда** — правило проекта.
  Бесплатный ключ Google — допустим как *запасная* в личном режиме (это ключ владельца, не FreeLLMAPI).
- **Младшие агенты** (личный режим): режимы доступа уже есть — `inherit` / `own` / `free`.
  - `inherit` («как у главного») — наследует и `fallbacks` главного.
  - `own` — свои основная + запасные, ключи в хранилище **этого** агента.
  - `free` — FreeLLMAPI; запасная — платная модель только если владелец явно включил (иначе можно незаметно
    тратить деньги).
- **Режим «компания» (команды проектов)**: FreeLLMAPI запрещён; китайские провайдеры — с предупреждением;
  запасные задаются на уровне команды (PM / разработчик / ревьюер могут быть разными).
- **Расписания**: по умолчанию используют `fallbacks` агента. Для дорогих моделей — галочка «в расписаниях
  не переключаться на платную» (`payload.fallbacks: []`).

## Логика в панели (что написать потом)

### Экран

Новая карточка «Модели» на экране главного агента (`AssistantView`) и шаг «Доступ к ИИ» в конструкторе младшего
(`AgentBuilderView`):

1. Выбор пресета или «Своя».
2. Список: **Основная**, **Запасная 1**, **Запасная 2** — у каждой провайдер, модель, статус ключа
   (подключён / нет / лимит до HH:MM / нет денег).
3. Кнопка «Подключить ключ» у запасной — ключ сохраняется, **основная не меняется**.
4. Кнопка «Проверить» — пробный запрос к каждой модели по очереди.
5. Перетаскивание порядка.
6. Подсказка с ценой за 1 млн токенов и примерной ценой в месяц (по данным экрана «Расход»).

### BFF

Новый модуль `apps/bff/src/models/` (или расширить `ai-setup`):

- `GET /api/agents/:id/models` → `{ primary, fallbacks[], profiles[] }` из `config.get` + `models.authStatus`
  (статус, `cooldownUntil`, `disabledReason` из usageStats, если Gateway их отдаёт).
- `PUT /api/agents/:id/models` → `patchConfig` с
  `agents.entries.<id>.model { primary, fallbacks }` и `replacePaths: ["agents.entries.<id>.model.fallbacks"]`.
- `POST /api/agents/:id/models/key` → сохранить ключ провайдера **без смены основной модели**.
  ⚠️ `openclaw.setup.activate` и наш `storeKeyWithModelViaWizard` ставят модель агенту. Надо проверить RPC:
  либо wizard с текущей основной моделью, либо `secrets.store.set` + `auth.profiles`. Написать probe-скрипт
  в `apps/bff/src/scripts/` (как `activate-probe.ts`) перед кодом.
- Подписка + ключ OpenAI: писать `auth.order.openai` (порядок профилей), а не `fallbacks`.
- Пресеты — константы в `packages/` (общие для web и BFF), с ценами и флагом `china: true`.
- Миграция: существующие Gemini-fallbacks превращаются в пресет «Только бесплатно» без потери.

### Подводные камни (проверить при реализации)

- ✅ `agents.update { model }` **сбрасывает** `fallbacks` (проверено). `#activateGeminiFlash` после него сам
  пишет запасные; «как у главного» в конструкторе копирует только основную — при переходе на цепочки копировать
  всю цепочку через `writeChain`.
- Каждая запасная модель требует **плагин провайдера** (`#install`, версия = версия Gateway) и ключ в хранилище
  того же агента (per-agent `openclaw-agent.sqlite`). Ключ главного младшему не виден, кроме `inherit`.
- Младшие в Docker-песочнице: сеть до нового провайдера должна быть разрешена (проверить egress).
- Telegram-группы: уведомления о переключении скрыты → показывать в панели (лента действий / журнал) по событию
  `model_fallback_decision`.
- Экран «Расход»: стоимость считать **по фактической модели**, а не по выбранной; добавить разбивку
  «основная / запасная».
- Бюджет: опционально лимит $/месяц на агента → при превышении снять платные запасные (позже).
- Ключи никогда не логируются (как сейчас в `ai activation`).

### Тесты

- Юнит: построение `fallbacks` из пресета, фильтр бесплатных для главного/компании, миграция Gemini.
- e2e на изолированном стеке (`COMPOSE_PROJECT_NAME=clawdesk-e2e`, см. память проекта): основная с
  заведомо неверным ключом → ход отвечает запасная, в чате есть `↪️ Model Fallback`.
- Не жечь бесплатный ключ Google тестами.
