# Режим компании: матрица возможностей и ограничений (этап 0, P0)

Дата: 05.11.2026. OpenClaw закреплён на версии 2026.8.35 (обновлено 05.11.2026, срез 38; контрактный тест — 11 из 11) (`deploy/openclaw.version`). Связанные документы: [ход работ](company-implementation-progress.md), живые проверки для владельца.

Здесь записано, на что панель опирается: какие операции OpenClaw, песочницы, Google, Telegram и GitHub реально используются, что проверено вживую, что только автотестами, и где граница — до того, как это обещано пользователю. Что есть на конкретной установке сейчас, показывает экран «Компания → Возможности установки» (`GET /api/system/capabilities`). Он проверяет связь с Gateway, версию OpenClaw, режим, модель главного агента, песочницу, Docker, плагин обращений, владельца в Telegram, Google и git.

Статусы:
- **вживую** — проверено на локальной установке, дата и срез в журнале;
- **автотесты** — покрыто тестами с подставным окружением; шаги живой проверки — в списке для владельца;
- **не проверено** — предположение о поведении OpenClaw или внешнего сервиса, которое подтвердит только живая проверка;
- **нет** — не поддерживается; обещать нельзя.

## Gateway: RPC и события

| Операция | Для чего | Статус |
| --- | --- | --- |
| `agents.list`, `agents.update`, `agents.delete` | список и правка агентов | вживую |
| `agents.files.get` / `agents.files.set` | AGENTS.md, SOUL.md, USER.md; блок обязанностей (срез 24) | вживую — файлы; автотесты — блок обязанностей |
| `config.get` / `config.patch` | инструменты, плагины, песочница, MCP-запреты, модели, Telegram | вживую на 2026.8.1; на 2026.8.35 — контрактный тест: изменение `models.providers` отвечает «нужен перезапуск», панель дожидается его (срез 38) |
| `chat.send` с `idempotencyKey` | задания исполнителям, сообщения агентам, доставка обращений | вживую (срезы 10, 13) |
| `chat.send` в отдельную сессию `agent:main:clawdesk-…` + событие `chat` (`final`) + `chat.history` | разовый вопрос модели: опрос о проекте, проверка противоречий (срезы 27–28) | автотесты; отдельная сессия не попадает в чат владельца — вживую 06.11.2026 (срез 27) |
| события `chat` и `agent` (инструменты) | активность и офис (срез 20) | автотесты |
| `send` (канал telegram) с `presentation.blocks[].buttons` | сообщение владельцу с кнопками (срез 15) | автотесты |
| `send` с `threadId` в группу | обращение в теме команды (срез 25) | не проверено: поле `threadId` взято из доставки расписаний в темы |
| `cron.*` | расписания агентов и доставка в темы | вживую |

## Песочница агентов

| Свойство | Значение | Статус |
| --- | --- | --- |
| источники bind | только внутри workspace агента; `/workspace` занят OpenClaw | вживую (срез 10) |
| рабочие копии исполнителей | `/workspace/project`; `app/` проекта в песочницу не попадает | вживую |
| общие папки и документы команды | синхронизируемые копии в workspace (`/workspace/folders/…`, `/workspace/docs`) | вживую (срезы 12, 14) |
| Google-документ | копия `/workspace/google/<id>.md` только для чтения | автотесты (срез 26) |
| Node.js и сеть в песочнице | нет: тесты запускает панель | вживую |
| `gog` в песочнице | нет | вживую (образ) |
| агент **без** песочницы | работает в контейнере Gateway: правила доступа к папкам и Google на него не действуют, у него есть `gog` с подключением владельца | **нет ограничения** — карточки доступов и обязанностей об этом предупреждают |

## Известные ограничения OpenClaw (2026.8.35)

- Патч запуска (`clawdesk-startup-migration-fix`) нужен и в 2026.8.35 и привязан к ней; линия 2026.11 отложена (новое хранение сессий).
- Мастер настройки OpenClaw падает с `AgentSelectionRequiredError` при нескольких агентах: панель останавливает его на шаге каналов. На 2026.8.35 не перепроверено — только вживую.
- Удаление агента и немедленный перезапуск Gateway могут оставить незавершённый журнал удаления (см. журнал, срез 10).
