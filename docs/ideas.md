# Идеи на будущее

Чего не хватает ClawDesk, по убыванию пользы. Появилось из сравнения с SimpleClaw Desktop (10.11.2026).

1. **Браузер для агентов.** Headless-браузер внутри песочницы, чтобы агент мог открывать сайты, заполнять формы и
   собирать данные. Самый заметный пробел.
2. **Ответы голосом в Telegram.** Распознавание голоса уже есть, не хватает ответа голосом.
3. **API для внешних систем.** Чтобы другие программы могли ставить задачи агентам и следить за их выполнением.
4. **Наблюдатель.** Замечает зависшие задачи и сообщает о них.

Не делаем: управление мышью и экраном компьютера (computer use). Это другая ниша и большой риск для пользователя;
агенты ClawDesk остаются в изолированных песочницах.
