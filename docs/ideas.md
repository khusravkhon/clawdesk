# Идеи на будущее

Чего не хватает ClawDesk, по убыванию пользы. Появилось из сравнения с SimpleClaw Desktop (10.11.2026).

1. **Браузер для агентов.** Headless-браузер внутри песочницы, чтобы агент мог открывать сайты, заполнять формы и
   собирать данные. Самый заметный пробел.
2. **Ответы голосом в Telegram.** Распознавание голоса уже есть, не хватает ответа голосом.
3. **API для внешних систем.** Чтобы другие программы могли ставить задачи агентам и следить за их выполнением.
4. **Наблюдатель.** Замечает зависшие задачи и сообщает о них.

## Сопровождение OpenClaw (сделать позже)

Решение 18.11.2026: остаёмся на OpenClaw, своё ядро не пишем. Чтобы обновления не ломали панель:

0. **Версия закреплена** — уже сделано (`deploy/openclaw.version`). Обновляемся, только когда нужна новая
   возможность или исправление, а не на каждый выпуск.
1. **Контрактный тест расширен** — сделано (18.11.2026). Все методы Gateway, которые вызывает панель
   (`apps/bff/src/contract/panel-methods.ts`, сверку держит `test/panel-methods.test.ts`), проверяются по
   `hello.features.methods`; большинство ещё и вызывается с параметрами панели. Плюс плагины из
   `deploy/plugins` и патчи `deploy/clawdesk-startup-migration-fix.mjs` в собранном Gateway.
   Правило: тест красный на новой версии — не обновляемся.
2. **Один слой-адаптер для OpenClaw.** Все вызовы Gateway собрать в одном модуле рядом с
   `apps/bff/src/gateway/gateway-service.ts`: методы с понятными именами (`createAgent`, `sendMessage`,
   `scheduleJob`…), остальной код вызывает только их. Сейчас Gateway упоминается примерно в 93 файлах BFF.
   После переноса изменение в OpenClaw правится в одном месте, а контрактный тест проверяет ровно этот слой.
   Оценка: 1–2 недели.

Не делаем: управление мышью и экраном компьютера (computer use). Это другая ниша и большой риск для пользователя;
агенты ClawDesk остаются в изолированных песочницах.
