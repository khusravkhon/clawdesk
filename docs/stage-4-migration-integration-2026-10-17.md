# Совместимость миграций личного режима

После применения `0009_personal_reminders` отдельный откат `0008_library_search` запрещён. Drizzle определяет выполненные миграции по последней записи журнала: удаление записи 0008 при сохранённой 0009 не приведёт к повторному выполнению 0008, оставив базу несовместимой с текущим приложением.

`rollback-library-search.sql` проверяет отсутствие более новых записей до изменения таблиц библиотеки. При отказе SQLite откатывает транзакцию целиком; данные библиотеки, напоминания и журнал сохраняются. Для возврата версии после применения 0009 нужна согласованная резервная копия базы и соответствующая версия приложения.

Проверка: `library-index.test.ts` — 6 тестов успешно. Проверены переход старой базы через 0008, разрешённый откат 0008, повторное применение 0008 и 0009 через `openDb`, а также отказ при применённой 0009 без изменения схемы, данных или журнала и без оставшейся открытой транзакции.
