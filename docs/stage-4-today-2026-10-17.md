# Этап 4: экран «Сегодня» личного режима

## Реализовано

- `/` открывает «Сегодня» только для personal, company сохраняет существующий Dashboard.
  `/today` недоступен как личная страница в company; API возвращает 404.
- Агрегатор `/api/today` объединяет независимые наблюдения: связь, очередь одобрений,
  короткие сведения о заметках, реальный статус поиска, фиксированные напоминания и
  ближайшие задания агентов. Одновременные запросы объединяются.
- Ошибка одного источника не обнуляет остальные: состояние `unknown`, данные последней
  успешной проверки и её дата сохраняются в памяти процесса. До первого успешного
  наблюдения данные и дата равны null. После перезапуска старые сведения не выдумываются.
- `checkedAt` поиска берётся из реального memory DTO: чтение кэшированного статуса не
  считается новой проверкой embeddings. Ошибки имеют приоритет над unchecked.
- Строгая очередь одобрений не выдаёт недоступную plugin-очередь за ноль запросов.
  Разрешение команд возможно только на существующем экране одобрений после просмотра.
- Telegram health — отдельное чтение без восстановления/изменения владельца и без
  превращения ошибки channels.status в stopped.
- Новые одноразовые напоминания: создание фиксированного текста, done/skip/snooze30,
  отдельные статусы доставки и выполнения, тихие часы и последние завершённые.
  API использует UUID операций и блокировку повторного клика; ошибка оставляет UUID
  для повтора. Неполная выдача до 200 записей явно помечена.
- Тихие часы касаются только новых фиксированных напоминаний. Существующие AIcron
  показаны отдельно со ссылкой управления; done напоминания их не меняет.
- Факты владельца, длинные материалы и здоровье поиска разделены ссылками. Нет платных
  AI summary, автоматической компрессии или удаления фактов. Pending заметки можно
  повторно применить существующим endpoint без создания новых записей.
- Фоновый опрос 30с не перекрывается, останавливается в скрытой вкладке и при offline.
  Начальное и ручное чтение, а также локальные действия пробуют localhost даже если
  navigator.onLine=false. Черновик нового напоминания и правки тихих часов сохраняются
  при обновлении; устаревший GET не перекрывает подтверждённую мутацию.
- RU/EN/TG переводы, адаптивная сетка, корректные подписи часового пояса напоминания.

## Проверки

- 7 focused Vitest проверок `apps/bff/test/today.test.ts`: даты реальной проверки,
  частичная недоступность/последние данные, null до первого успеха, singleflight,
  строгие approvals, company404 и доступность локальных напоминаний при Gateway offline.
- Elevated BFF tsc, Vue vue-tsc и Vite build прошли. Обычный sandbox не читает часть
  symlink зависимостей и даёт массовые ложные ошибки экспортов Vue/Response/Vitest.
- Браузерные и полные интеграционные проверки выполняются отдельно в итоговой проверке
  этапа. В этом изменении не запускались пользовательский/verify Docker стек, реальные
  Telegram сообщения, commit, push или deploy.

## Ограничения

- Наличие сохранённого статуса поиска не доказывает его работу сейчас: дата последней
  проверки показана явно; при потере связи отображается unknown.
- «Доставлено» означает подтверждение Telegram API, а не прочтение владельцем.
- Новый одноразовый механизм не добавляет done к старым recurring AI заданиям.
- Исторические значения агрегатора живут в процессе BFF и не подменяют постоянные
  записи напоминаний и заметок в базе.
