# Политика конфиденциальности

**Дата вступления в силу:** 21.11.2026

## 1. Кто мы

ClawDesk — открытое программное обеспечение, которое пользователь устанавливает на свой компьютер или сервер («установка»). Разработчик ClawDesk не предоставляет облачный сервис и не получает данные пользователей.

## 2. Возраст

ClawDesk предназначен только для лиц старше 18 лет. Устанавливая и используя ClawDesk, вы подтверждаете, что вам исполнилось 18 лет.

## 3. Какие данные мы храним

**Никакие.** Разработчик ClawDesk не собирает, не хранит и не получает данные пользователей: ни учётные записи, ни файлы, ни переписку, ни данные Google. В ClawDesk нет аналитики и сбора статистики.

Все данные, которые пользователь подключает к ClawDesk, хранятся только на его собственной установке. Хранение, защита и резервное копирование этих данных — ответственность пользователя.

## 4. Данные Google

Только если пользователь сам подключит свой аккаунт Google и только для выбранных им сервисов, ClawDesk на его установке получает доступ к:

- **Gmail** — чтение писем; с разрешения пользователя — подготовка, отправка писем и метки;
- **Google Drive** — список и чтение файлов; с разрешения — создание и изменение файлов;
- **Google Docs и Sheets** — чтение документов и таблиц; с разрешения — их изменение;
- **Google Calendar** — чтение событий; с разрешения — создание и изменение событий.

По умолчанию запрашивается доступ только на чтение.

**Как используются данные Google.** Только для того, о чём пользователь просит своих ИИ-агентов (например, «покажи письма за сегодня» или «найди договор в Drive»). Данные Google не используются для рекламы, не продаются, не передаются разработчику ClawDesk и не используются для обучения моделей ИИ.

**Где хранятся.** Ключи входа Google хранятся в зашифрованном виде только на установке пользователя. Чтобы выполнить просьбу, агент передаёт нужную часть данных выбранному пользователем провайдеру ИИ (например, Anthropic, OpenAI или Google) по правилам этого провайдера.

**Limited Use.** Использование и передача ClawDesk информации, полученной через API Google, соответствуют [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включая требования Limited Use.

## 5. Сторонние сервисы

Провайдеры ИИ, Google, Telegram и другие сервисы, которые пользователь подключает к ClawDesk, работают по своим правилам и политикам конфиденциальности. Разработчик ClawDesk за них не отвечает.

## 6. Удаление данных

Пользователь может в любой момент отключить Google в ClawDesk («Источники данных → Google → удалить аккаунт») — ключи входа удаляются с установки. Доступ также можно отозвать на странице [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Удаление ClawDesk удаляет всё, что он хранил на установке.

## 7. Изменения

Политика может обновляться; новая версия публикуется на этой странице с новой датой.

# Privacy Policy (English)

**Effective date:** 21 November 2026

**Who we are.** ClawDesk is open-source software that the user installs on their own computer or server. The ClawDesk developer does not run a cloud service and does not receive users' data.

**Age.** ClawDesk is only for people aged 18 and over. By installing or using ClawDesk you confirm that you are at least 18.

**Data we store: none.** The ClawDesk developer does not collect, store or receive any user data — no accounts, files, messages or Google data. ClawDesk has no analytics or telemetry. All data the user connects stays on the user's own installation; storing, protecting and backing it up is the user's responsibility.

**Google user data.** Only if the user connects their Google account, and only for the services they select, ClawDesk on the user's installation accesses: Gmail (reading; with permission, drafting, sending and labelling), Google Drive (listing and reading; with permission, creating and changing files), Google Docs and Sheets (reading; with permission, editing) and Google Calendar (reading; with permission, creating and changing events). Read-only access is the default.

Google data is used only to do what the user asks their AI agents to do. It is not used for advertising, not sold, not sent to the ClawDesk developer and not used to train AI models. Google sign-in tokens are stored encrypted on the user's installation only. To answer a request, the agent sends the relevant part to the AI provider the user has chosen (for example Anthropic, OpenAI or Google), under that provider's terms.

**Limited Use.** ClawDesk's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Third-party services** the user connects (AI providers, Google, Telegram and others) are governed by their own terms and policies.

**Deleting data.** Disconnect Google in ClawDesk (Data sources → Google → remove account) to delete the tokens, or revoke access at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Uninstalling ClawDesk deletes everything it stored.
