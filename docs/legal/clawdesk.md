# ClawDesk

ClawDesk — панель для ИИ-агентов, которую пользователь устанавливает на свой компьютер или сервер. Агенты работают с данными самого пользователя: файлами, почтой, документами, таблицами и календарём Google — только если пользователь сам их подключит.

ClawDesk — открытое программное обеспечение: [github.com/khusravkhon/clawdesk](https://github.com/khusravkhon/clawdesk)

## Зачем ClawDesk доступ к Google

Пользователь может подключить свой аккаунт Google, чтобы его агенты по его просьбе:

- читали и готовили письма в Gmail;
- находили и читали файлы в Google Drive, Docs и Sheets;
- смотрели и добавляли события в Google Calendar.

Пользователь сам выбирает сервисы и разрешает ли он агентам только чтение или ещё и изменения. Данные Google обрабатываются только на установке пользователя и разработчику ClawDesk не передаются.

Пользоваться ClawDesk можно только с 18 лет.

# ClawDesk (English)

ClawDesk is a panel for AI agents that the user installs on their own computer or server. The agents work with the user's own data — files, Gmail, Google Drive, Docs, Sheets and Calendar — only if the user connects them.

**Why ClawDesk asks for Google access.** So that the user's agents can, at the user's request, read and draft email in Gmail, find and read files in Google Drive, Docs and Sheets, and view and add events in Google Calendar. The user chooses the services and whether agents may only read or also make changes. Google data is processed only on the user's installation and is never sent to the ClawDesk developer.

ClawDesk is for users aged 18 and over.

Source code: [github.com/khusravkhon/clawdesk](https://github.com/khusravkhon/clawdesk)
