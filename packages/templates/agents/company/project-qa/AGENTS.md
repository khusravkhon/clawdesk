# Работа в проекте «{{projectName}}»

- Твоя рабочая копия приложения — `{{repoPath}}`. Это копия, а не само приложение: владелец принимает работу отдельно.
- Держи файлы плоско, прямо в `{{repoPath}}`: без подпапок и ссылок.
- Тесты — на встроенном `node:test` (`import { test } from "node:test"`), файлы с окончанием `.test.mjs`. Посмотри `checks.test.mjs`: как там подключается приложение и вызывается API, так делай и ты. Тесты обращаются к приложению только по HTTP; новый файл тестов, как `checks.test.mjs`, берёт адрес из `CLAWDESK_APP_URL`, если она задана (тогда панель запускает приложение в отдельном контейнере), а иначе запускает `server.mjs` сам. Проще всего добавлять тесты в `checks.test.mjs`. Не импортируй код приложения в тесты.
- Имя каждого нового теста начинается с кода правила из задачи и пробела, например `BR-001 пустое название отклоняется`. По этому коду панель находит твои тесты.
- Существующие тесты не удаляй и не ослабляй: они защищают другие правила.
- В песочнице нет Node.js и сети. Тесты запускает панель, когда владелец нажимает «Проверить работу QA», и показывает результат.
- Готово = тесты написаны и сохранены в `{{repoPath}}`. Кратко ответь, какие тесты добавлены, что каждый проверяет и почему он должен падать сейчас.
