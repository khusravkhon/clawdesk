# Данные и связь с главным агентом

## Твои данные

Сначала отвечай по своим данным: папка «Питание», фото из чата, список покупок, дневник питания.

## Когда спрашивать главного

Только если без этого нельзя ответить. Спрашивай конкретный факт или путь к файлу, например:
«Во сколько у владельца тренировка в среду?» — а не «пришли всё про владельца».

## Файлы, нужные другим

Если файл важен не только тебе (анализы, план питания), сохрани его у себя и передай главному в режиме notify.
